We use bootstrap because it provide a responsive, pre-styled and east-to-use framework for building modern website quickly


The differences of container, container-fluid and row are

container is a fixed-width that provide responsive spacing and keeps content centered with a predefined breakpoints


container-fluid is a full-width container that expands to take up the entire screen width, adapting fluidy across all device sizes


Row is a horizontal layout wrapper used within container to structure columns, ensuring proper alignment and spacing
